# Vital 40+ — project notes

The owner is not a programmer and writes in Arabic (Maghrebi dialect): reply in Arabic, explain simply, and make technical decisions yourself.

## What the app is
A multilingual (en / fr / ar, RTL for Arabic) healthy-eating PWA for adults over 40, aimed at Europe and the US.
Main features: meal photo → Claude estimates foods, grams and nutrients → portion advice per health focus
(blood sugar, triglycerides, blood pressure & salt, cholesterol, thyroid); "My plan" tab with foods to eat / limit /
keep occasional, a sample day and exercise timed around meals, read aloud with the device's speech synthesis;
food diary, guide, habits, exercise, privacy (export / import / delete).

## Decisions already made
- **Stay a general wellness tool, not a medical device** (EU MDR / FDA). Removed on purpose: classifying blood sugar /
  blood pressure / lab readings, alerts, HbA1c estimate, diabetes risk test, medication reminders, doctor report,
  Ramadan medical thresholds. Do not re-add them without the owner understanding the legal risk.
  Wording uses "health focus" and healthy-eating framing, never treatment instructions.
- Advice is deterministic (`public/advice.js` nutrient caps), not generated by the AI; the AI only estimates nutrients.
- Photo analysis: `server.js` → `claude-opus-5-5`, structured output (zod), `fallbacks: "default"`, per-IP rate limit.
  Needs `ANTHROPIC_API_KEY`. Photos are not stored.
- Profile and diary live only in the browser (localStorage).

## Run / test
`npm install && ANTHROPIC_API_KEY=... npm start` → http://localhost:8000.
To test without a key, point `ANTHROPIC_BASE_URL` at a local fake that returns a message whose text is the JSON
`{is_food, confidence, items:[{name, grams, kcal, carb, fib, sug, pro, sat, chol, na}]}`.
Every UI string must exist in all three languages in `public/i18n.js`; content lives in `public/content-*.js`.
