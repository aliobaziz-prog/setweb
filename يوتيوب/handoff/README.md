# بروتوكول التسليم بين Claude السحابي (الهاتف) وClaude Code على الحاسوب

الفكرة: Claude السحابي (المدير) يخطط ويبحث ويكتب المهام، وClaude Code على الحاسوب ينفّذ ما يحتاج الحاسوب (المونتاج، الملفات المحلية، البرامج، المهارات المثبتة هناك). قناة التبادل هي هذا المجلد داخل المستودع (git).

## المجلدات

| المجلد | من يكتب فيه | ماذا فيه |
|---|---|---|
| `to-computer/` | Claude السحابي | مهام (برومبتات) جاهزة لينفذها Claude Code على الحاسوب |
| `from-computer/` | Claude Code على الحاسوب | نتيجة كل مهمة: ما تم، والملفات، والمشاكل |
| `done/` | الاثنان | المهام المنتهية تُنقل إليها مع نتيجتها |

## دورة العمل

1. **المدير (السحابي)** يكتب مهمة في `to-computer/` باسم `NNN-اسم-قصير.md` (مثل `001-montage-episode-4.md`) بقالب `TEMPLATE.md`، ثم يرفعها (commit وpush) ويخبر المالك.
2. **على الحاسوب:** يفتح المالك Claude Code في مجلد المشروع ويكتب: `git pull` ثم «نفّذ المهام الجديدة في يوتيوب/handoff/to-computer».
3. **Claude Code** ينفذ المهمة، ويكتب النتيجة في `from-computer/NNN-...-result.md`، ثم commit وpush.
4. **المدير** يسحب النتيجة (يقرأها من المستودع)، ويراجعها، وينقل المهمة إلى `done/`، ويكمل المسار.

## قواعد

- ملف واحد لكل مهمة، والبرومبت كامل بذاته: لا يعتمد على ذاكرة المحادثة.
- كل مهمة تذكر: الهدف، والمدخلات (مسارات الملفات)، والمخرجات المطلوبة، وقواعد القناة (لا وجوه رجال، لا نسخ، حقوق الصور والموسيقى).
- لا أسرار في المستودع: لا كلمات سر ولا مفاتيح ولا روابط خاصة.
- الملفات الكبيرة (فيديو، صوت) لا تُرفع إلى git؛ تُحفظ في Google Drive ويُكتب رابطها في النتيجة.
- Claude Code على الحاسوب لا ينشر شيئاً على يوتيوب ولا يرسل شيئاً خارجياً دون إذن صريح من المالك.
- عند التعارض: قواعد `يوتيوب/company.md` أولاً، والقرار للمالك.
