# صحتي بعد الأربعين (setweb)

تطبيق ويب (PWA) بالعربية لمن تجاوزوا 35–40 سنة، يساعد على الوقاية من الكوليسترول والتريغليسريد وارتفاع الضغط والسكري وأمراض الغدد عبر الأكل والرياضة.

## المزايا
- ملف صحي (العمر، الوزن، الطول، الأمراض) مع حساب مؤشر كتلة الجسم ونصائح مخصصة.
- دليل الأكل: كُل / بحذر / تجنّب حسب حالتك.
- مقترحات وجبات يومية بنكهة مغاربية، وطبق الصحة.
- تمارين رياضية وبرنامج أسبوعي مع تحذيرات حسب المرض.
- متابعة يومية (أهداف) وسجل قياسات (سكر، ضغط، وزن، تحاليل) محفوظ على جهازك.

## التشغيل
تطبيق ثابت بدون بناء:

```
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## تنبيه
المحتوى للتوعية العامة ولا يغني عن استشارة الطبيب أو أخصائي التغذية.
