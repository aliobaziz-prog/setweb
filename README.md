# صحتي بعد الأربعين (setweb)

تطبيق ويب (PWA) بالعربية لمن تجاوزوا 35–40 سنة، للوقاية من الكوليسترول والتريغليسريد وارتفاع الضغط والسكري وأمراض الغدد عبر الأكل والرياضة والمتابعة.
مبني على أفضل ما في التطبيقات العالمية (Cronometer، mySugr، Qardio، Cholesterol Tracker، DASH، Noom/Omada) مع إضافات تخص منطقتنا.

## المزايا
- **يومياتي الغذائية:** قاعدة أطعمة (منها المغاربية: حريرة، كسكس، طاجين، بريك، تمر…) تحسب السعرات والكربوهيدرات والسكر المضاف والدهون المشبعة والصوديوم والكوليسترول والألياف مقابل أهداف مخصصة لحالتك، مع إمكانية إضافة طعامك.
- **القياسات والتحاليل:** سكر، ضغط، وزن، HbA1c، LDL، HDL، كوليسترول، تريغليسريد. ألوان حسب المدى، رسوم بيانية، متوسطات، تقدير HbA1c، تنبيهات للقراءات الخطيرة، ووحدة غ/ل أو مغ/دل.
- **أدويتي:** قائمة ومتابعة يومية وتذكير.
- **اختبار خطر السكري (FINDRISC)** وأرقام مرجعية للتحاليل.
- **وضع رمضان:** إرشادات الصيام والإفطار والسحور لمرضى السكري والضغط.
- **تقرير للطبيب:** ملخص 30 يومًا قابل للطباعة/PDF.
- دليل «ماذا آكل؟»، وجبات مقترحة، تمارين وبرنامج أسبوعي، أهداف يومية، ومعلومة يومية.
- يعمل دون إنترنت، والبيانات محفوظة على جهازك فقط.

## التشغيل
تطبيق ثابت بدون بناء:

```
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## تنبيه
المحتوى للتوعية العامة ولا يغني عن استشارة الطبيب أو أخصائي التغذية. القيم الغذائية تقريبية.
